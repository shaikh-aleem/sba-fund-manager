# SBA Fund Manager

**Interest-Free Community Fund Management System**

A digital platform for managing a community mutual support fund — member registration, monthly contributions, interest-free loans, EMI tracking, and transparent fund management.

## Features

- 🔐 Role-based access (Super Admin, Admin, Member)
- 👥 Member registration with approval workflow
- 💰 Monthly contribution tracking (₹500/month)
- 🧾 Digital receipts
- 📊 Live fund dashboard
- 💵 Interest-free loans (after 1-year lock-in)
- 📅 EMI tracking and repayment
- 📈 Financial reports

## Tech Stack

- **Frontend:** Next.js 14
- **Database:** Supabase (PostgreSQL)
- **Hosting:** Vercel
- **Auth:** Custom JWT with bcrypt

## Rules

- Monthly contribution: ₹500 per member
- Collection window: 1st–10th of every month
- Loan lock-in: 1 year minimum before any loans
- Reserve rule: Always retain 10% of total fund
- Loans only to members, no interest charged
